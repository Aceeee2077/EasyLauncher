# 自动好友联机

本功能面向 Windows x64 的 Minecraft Java 服务器。首次在“联机开服”点击“开启自动联机”，再点击“前往 playit 授权”。用户在官方网页登录并批准；若要求验证邮箱，需要完成验证。应用自动创建 Minecraft Java TCP 隧道，用户不用安装 frpc、填写配置或设置路由器。首次授权在本机各服务器间共享；每个服务器分别开启联机。

之后直接启动服务器即可。软件自动下载并校验官方 playit 独立客户端，启动连接并探测公网地址的 Minecraft 状态响应。验证成功才开放复制地址，并把地址传给邀请卡。朋友无需安装 playit。停止服务器会关闭该服的本地转发及已有连接；所有联机服务器停止后，代理进程退出。网络连接恢复后客户端自行重连；子进程退出后由应用重启。

## 边界

- 使用 playit 的账号、免费额度及自动分配线路；软件不购买套餐、不保证线路延迟。供应商额度不足、邮箱未验证、网络不可达会显示错误。
- 应用关闭后联机停止。服务商端保留隧道以复用地址，不在每次关服时删除；不再使用的隧道可以在 playit 管理页面删除以释放额度。
- 公网探测从房主电脑访问服务商公网入口，验证 Minecraft 状态协议；还需要朋友在其他网络实际加入验收。`enable-status=false` 会使探测无法通过。
- 当前只覆盖 Java TCP 游戏端口；基岩版、语音聊天 UDP、网页地图不在此功能范围。
- 手动 frp、UPnP、局域网诊断保留在“高级网络设置”。授权失效时先停止所有服务器，再点击“重新授权”。旧账号中的隧道需在服务商网页清理。

## 实现和凭据

- API：官方 `/claim/setup`、`/claim/exchange`、`/agents/rundata`、`/tunnels/list`、`/tunnels/create`、`/tunnels/update`。
- 使用 `assignable` agent，应用只创建名称为 `EasyLauncher-<server UUID>` 的 Minecraft Java 隧道，自动选择本地回环转发端口。每台运行中的服务器拥有独立转发任务；关服会结束任务并关闭连接。
- `playit.json` 位于应用数据目录，保存开关及隧道 ID。凭据由现有 DPAPI vault 加密保存；不放入服务器导出包、前端、命令行参数或日志。子进程通过 `PLAYIT_SECRET` 环境变量获得凭据。
- 固定使用官方仍支持的独立版 **v0.17.1**，避免将 v1 服务安装器误当作可托管子进程。下载 Windows x64 signed EXE；SHA-256 为 `9b00d6ff7d37d1052e5ae097e1348e11deae8617cd7a8ba39d1777f2006316a3`。每次启动前校验缓存文件。升级版本需重新核对参数和哈希。
- 参考：[官方源码](https://github.com/playit-cloud/playit-agent/tree/v0.17.1)、[发布页](https://github.com/playit-cloud/playit-agent/releases/tag/v0.17.1)、[支持页面](https://playit.gg/support/)。

## 验收

自动测试覆盖公网地址解析、协议响应识别、API 请求限制、转发和连接清理，以及授权入口、未验证地址禁止分享、关闭联机清空地址。构建通过不等于公网验收完成。

实际验收需在桌面应用中完成首次授权，开服后等待公网验证成功，然后用手机热点或异地玩家的 Minecraft 客户端加入；验证停服断开、再次开服复用地址、断网恢复，以及两个服务器同时运行时互不干扰。
