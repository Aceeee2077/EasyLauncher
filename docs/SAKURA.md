# 樱花 FRP 自动穿透

本功能面向 Windows x64 的 Minecraft Java 服务器，并要求本机已安装樱花启动器（默认 `C:\Program Files\SakuraFrpLauncher\frpc.exe`）。

## 使用方式

1. 在“联机开服”的“樱花 FRP”卡片中粘贴访问密钥。密钥来自[樱花用户信息页面](https://www.natfrp.com/user/profile)，不是账户登录密码。
2. 密钥通过官方 `GET /v4/user/info` 验证一次后，用 Windows DPAPI 加密保存在应用数据目录的密钥库中；前端、日志、命令行参数和服务器导出包都不会包含它。
3. 选择线路节点并点击“开启樱花穿透”。这是每台服务器唯一一次需要配置的操作。
4. 之后启动服务器时，应用会自动查找或创建名为 `EasyLauncher-<服务器 UUID 前 12 位>` 的 TCP 隧道，把本地端口更新为服务器的实际端口，并用本机 `frpc.exe` 连接。停止服务器会结束 frpc。
5. 公网地址由“节点域名 + 隧道公网端口”组成。应用会从本机连接该地址，完成 Minecraft 状态协议握手后才允许复制地址和写入分享卡。

切换服务器的 `server.properties` 端口后，最多约一分钟内会自动调用 `/v4/tunnel/edit` 更新隧道的本地端口并重连。删除樱花面板中的隧道后，下次连接会重新创建。

## 凭据与进程

- 访问密钥保存在现有 DPAPI 密钥库（`sakura.token`），仅在启动 frpc 时通过 `NATFRP_TOKEN` 环境变量传递；隧道 ID 通过 `NATFRP_TARGET` 传递。两者都是樱花官方 frpc 自 `v0.39.1-sakura-1.1` 起支持的环境变量，避免密钥出现在进程命令行中。
- frpc 以隐藏窗口启动，参数 `-n` 跳过更新检查，并加入应用的任务对象；应用正常退出或异常终止时都会清理。
- 更换或清除密钥会重启所有正在运行的樱花穿透连接。清除密钥不会删除服务商端的隧道，重新填写后会复用。
- 应用不会读取樱花启动器或 SakuraFrpService 的配置，不会导入其中的密钥，也不会管理用户在樱花面板里创建的其他隧道。

## 节点与公开游戏服务器规则

樱花 FRP 对**公开游戏服务器**有强制节点限制：把连接方式发布到论坛、服务器列表、QQ 大群，或在 B 站、抖音、小红书等平台宣传、招人，都属于公开服务器。此类服务器必须使用 `flag & (1 << 11) != 0` 的专用节点（界面标记为“多线”），否则可能被封号且不退款。

小群熟人联机不属于公开服务器，可以使用普通节点。界面中普通节点排在前面，带“多线”标记的节点会单独标注，由用户按实际用途选择。

默认节点只从“允许创建隧道且未离线”的节点中选择，并优先免费（非 VIP）节点。账户额度不足、节点满载、隧道数量达到上限时，会显示服务商返回的错误。

## 边界

- 只覆盖 Java 版 TCP 游戏端口；基岩版、语音聊天 UDP 和网页地图不在此功能范围。
- 需要 `server.properties` 中 `enable-status=true`（默认值），否则公网 Minecraft 探测无法通过。此时代码仍会建立隧道，但界面不会开放复制地址。
- 应用关闭后联机停止。服务商端保留隧道以复用地址；不再使用时可在樱花面板删除以释放额度。
- 不要在同一条隧道上同时运行樱花启动器/服务和本应用，否则会争用同一连接。应用只启动自己创建的 `EasyLauncher-*` 隧道。
- 与 playit 自动联机二选一即可，同时开启会产生两条独立隧道和两个地址。
- 线路延迟、带宽、免费额度由樱花 FRP 提供；应用不购买套餐、不保证线路质量。

## 实现

- API：官方 `GET /v4/user/info`、`GET /v4/nodes`、`GET /v4/tunnels`、`POST /v4/tunnels`、`POST /v4/tunnel/edit`，使用 `Authorization: Bearer <访问密钥>`。
- `sakura.json` 保存每台服务器的开关、隧道 ID 和节点 ID；不保存地址或密钥。
- 每台运行中的服务器使用独立的 frpc 进程，按服务器状态启动和停止；同一时间最多进行一次节点列表刷新（缓存 30 分钟）。
- 自动测试覆盖节点 Flag 解析、节点排序、公网地址与端口校验、不安全域名拒绝以及服务商错误文本清理。

实际验收需要在桌面应用中填写密钥、开启穿透、启动服务器，等待公网状态验证成功，再用手机热点或其他网络中的 Minecraft 客户端加入；同时验证停止服务器断开、再次开服复用地址、修改端口后自动更新，以及两台服务器同时运行时互不干扰。
